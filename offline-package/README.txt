产品定位路标（离线版）
================================================

使用方法
--------
双击 product-roadmap-offline.html 即可在浏览器打开，无需安装任何软件。
建议使用 Chrome / Edge / Safari 较新版本。

数据口径
--------
销量与销售额为卖家精灵估算值，非 Amazon 官方数据，仅用于内部竞品定位分析。
缺失数据如实显示"暂无数据"，未做推测。

联网说明
--------
商品缩略图直接引用源站图片服务器，查看图片需联网；
不联网时布局与交互不受影响，仅缩略图无法显示。
